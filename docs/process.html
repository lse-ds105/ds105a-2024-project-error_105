Pokémon Biome Mapping Project

This project maps Pokémon to real-world biomes based on their strengths and types, leveraging Pokémon data, geographic information, and climate datasets.

Step 1: Pokémon Data Analysis (Using PokeAPI)

This step focuses on extracting, processing, and ranking Pokémon data using the PokeAPI.

Key Activities:

  • Comprehensive Pokémon Data Extraction: Queried the PokeAPI to retrieve Pokémon stats, types, and sprite images using asynchronous methods.
  • Ranking Pokémon: Calculated total stat scores and assigned rankings on a scale of 1–100, with the strongest Pokémon matched to extreme environments.
  • Filtering Pokémon by Type: Specialized filtering for Fire, Ice, and Water types to match them to specific biomes.
  • Data Storage: Stored structured data in JSON files and an SQLite database for further analysis.

Outputs: Cleaned Pokémon dataset with rankings, stats, and types.

Step 2: Extracting Biomes from Google Earth Engine

This step identifies real-world biomes using the Google Earth Engine (GEE) API.

Key Activities:

  • Utilized the Ecoregions 2017 Resolve Dataset to classify biomes such as deserts, forests, and tundras.
  • Calculated centroids for 1,500+ biomes globally to represent each biome.
  • Authenticated Google Earth Engine using a service account to automate the data extraction process.
  • Batch-processed biome data to optimize runtime and ensure consistency.

Outputs: A structured dataset of biome centroids with geographic coordinates.

Step 3: Climate Data Analysis (Using Open-Meteo)

Fetched and analyzed climate data for the identified biome centroids to rank the hottest, coldest, and wettest locations. We also leveraged forecasted climate data to predict where Pokémon might move in the future.

Key Activities:

  • Data Collection: Used Open-Meteo to retrieve both historical and forecasted temperature and rainfall data for biome centroids.
  • Asynchronous Requests: Leveraged asyncio to process large volumes of data efficiently.
  • Daily Updates: Updated maps on a daily, refreshable basis to reflect real-time and forecasted Pokémon migrations based on climate trends.
  • Pokémon Movement Tracker: Investigated how much Pokémon moved between biomes over time, enabling a Pokémon movement tracker feature.

Outputs: Ranked list of locations based on climatic extremes and Pokémon migration patterns.

Step 4: Mapping Pokémon to Biomes

This step matches ranked Pokémon to biomes based on their types and strengths and visualizes the results on an interactive map.

Key Activities:

  • Matching Pokémon to Biomes: Assigned Pokémon to biomes based on rankings, e.g., the strongest Fire-type Pokémon matched to the hottest biome.
  • Interactive Mapping: Used Folium to create interactive maps showing Pokémon distributions across biomes.
  • Geographical Analysis: Performed regression analysis to understand how latitude and longitude influence climate extremes and Pokémon distribution.

Outputs: Interactive maps displaying Pokémon distributions and movements.
